### 🔨 Featured Projects

**[Zoho Notes Pro](https://github.com/Fayasktr/zohoNotesPro.dev)** — Interactive Code Notebook & Runner
- A web-based notebook where you can write Markdown notes and execute code in JavaScript, TypeScript, Python, Java, and C/C++.
- Uses Monaco Editor (same editor as VS Code) with code completion, line numbers, and shortcuts.
- **Live Review feature:** Run cells with `Ctrl + Enter` and see output and results instantly under each cell.
- Connected Google Gemini AI to help explain code, suggest optimizations, and debug errors.
- Works offline as a PWA using service workers, local storage backups, and WebSocket syncing.
- Safe backend built with Express 5, MongoDB session storage, Google OAuth login, and rate limiting.

**Events & Venue Platform** — Production Group Project
- A collaborative team project for finding events, buying tickets, and booking venues.
- Responsible for frontend component structure, team GitHub workflows, and connecting APIs to the UI.
- Built to handle real-world users and getting ready for a production release.

**[ZiGo](https://github.com/Fayasktr/ZiGo)** — Electronics & Gadgets E-Commerce Store
- Full-stack shopping app built with Node.js, Express, MongoDB, EJS, and Tailwind CSS.
- Features Google OAuth + OTP login, product variants, coupon codes, and an admin dashboard.
- Integrated Razorpay for payments, Cloudinary for images, cart, wishlist, and order tracking.

**[User Management with Clean Architecture](https://github.com/Fayasktr/user_management_clean_architecture)**
- An admin and user management app following clean architecture rules.
- Keeps entities, use cases, and controllers separated so the business logic stays clean and testable.

**[LifeNavigator.ai](https://github.com/Fayasktr/lifenavigator.ai)** — AI Task & Life Planner
- Designed the core structure and MVP roadmap for an AI-assisted daily planner and task coordinator.

**Future Club Attendance Script** — Google Forms + Apps Script
- Built an automated script to process student attendance, match names, and generate reports.
